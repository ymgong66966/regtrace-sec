# License Notes

Before public upload, confirm the final license choice. For anonymous review, it
is acceptable to include these license notes and defer the final public-release
license decision, but the submitted artifact should be explicit about what each
file family represents.

Recommended release structure:

- Code: MIT License.
- Derived benchmark metadata, labels, and snippets: CC BY 4.0 or CC BY-NC 4.0, depending on author preference.
- SEC EDGAR source documents remain public source material from SEC EDGAR; the repository should release accession identifiers and retrieved snippets, not claim ownership over source filings.
- CMS and FDA probe data should follow the terms of their public source
  datasets. Prefer releasing derived benchmark examples and source identifiers
  rather than redistributing large raw archives.

If the repository is used for anonymous review, remove author-identifying metadata and use an anonymous repository service.
